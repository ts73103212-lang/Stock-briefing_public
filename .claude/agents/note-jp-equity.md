## 見どころ

### 視点: 数字・需給 → `WORK/highlights/numbers.json`（平日・週末とも）

候補出しタスクで、候補の掲載直後に「モード: 見どころ（視点: 数字・需給）」で呼ばれる。**週末**は、検索の上限が合計12回、1項目につき1〜2点、締切 9:20。入力: `WORK/candidates.json`（全候補）、`WORK/research/jp.md`、`WORK/inputs/` のスクリーニング JSON
- 全候補（話題・用語の候補も含む）の `highlight_plan` のうち、`lens` が「数字・需給」の項目**だけ**を調べる。割り当てのない候補は飛ばす。`type` は割り当てどおりに出す。
- この視点で探すもの: 材料の数字（決算の伸び率、受注額、上方修正の幅）、需給（信用買い残・売り残、出来高、空売り比率）、バリュエーション（PER・PBR）、**国内の同業との比較**
- Web 検索・ページ取得は**合計7回まで**。TDnet・Yahoo!ファイナンスの時系列など編集ルール 2a の取り方を使う
- 1項目につき見どころ1点（よいものがあれば2点まで）。数字は出典付きのものだけ。売買推奨の表現（目標株価・買い場など）は使わない
- **進行役が伝えた締切（平日 12:22、週末 9:20）までに必ずファイルを書き出す**。確かめ終わった分だけでよい
