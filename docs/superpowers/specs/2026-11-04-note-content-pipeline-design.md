# note / X 発信パイプライン 設計書

- 作成日: 2026-11-04
- 対象アカウント: note `aicorgi_frank17` / X（同コーギーアイコン）
- 位置づけ: 既存の株データ取得（GitHub Actions）と既存Claude定期タスク群の上に「発信レイヤー」を追加する

## 1. 目的と段階

| 段階 | ゴール | 主な指標 |
|---|---|---|
| A. 継続 | 1日15分以内の作業で note を毎日投稿できる | 連続投稿日数 |
| B. 集客 | note / X のフォロワー・閲覧数を伸ばす | フォロワー数・PV |
| C. 収益 | 週1本の有料記事（100〜300円）を売る | 有料記事の購入数 |

将来、YouTube を加えて note・X・YouTube の3本柱を相互リンクする（本設計の対象外）。

## 2. 前提・制約

- **法令**: 金融商品取引法上の投資助言に当たらないよう、売買推奨表現（「買い」「目標株価」「損切り」「推奨」「今がチャンス」等）を使わない。市場解説・データ分析・自分の視点の形にする。全記事の末尾に免責文「🐾投資判断はご自身で🐾」。
- **著作権**: 新天地メルマガ（`mailmag@mag2premium.com`）は「何が話題か」を知るためのシグナルとしてのみ使う。本文の転載・要約の掲載はしない。
- **note への投稿は手動**: note に公式投稿APIがないため、非公式API・Cookie利用による自動投稿はしない（アカウント凍結リスク回避）。
- **保存先**: 本リポジトリは公開のため、記事本文（特に有料記事）は置かない。生成物は非公開アーティファクトにのみ置く。リポジトリには図表生成コードとブランド素材のみ。
- **X投稿文**: 損切・目標価格などの売買指示を含めない（既存の朝ブリーフィングのメール内容は変更しない）。

## 4. 日次タスク（平日 16:15 JST 起動）

### 4.1 処理の流れ

1. 東証休場日なら何もせず終了。
2. 材料収集
   - リポジトリ: `screening_result_closing.json` / `screening_stophigh_closing.json` / `macro_result_closing.json`
   - Gmail: 新天地メルマガ直近3〜4通（HTMLの青字・赤字強調を解析）、当日の「【今日の相場振り返り】」メール
3. ネタ選定
   - テーマ記事1本: メルマガ・ニュース・当日セクター動向が重なるテーマを優先
   - 注目銘柄記事2本: ストップ高・出来高急増・メルマガ言及銘柄から、業種が重ならないよう選ぶ。直近14日に書いた銘柄は除外（過去の納品ページの履歴で判定）
4. Web検索で決算・IR・ニュースの事実確認。出典を確認できた数字だけを使う。
5. 記事3本・図表・X投稿文を生成。
6. 納品ページ（非公開アーティファクト、固定URL）を上書き公開。
7. プッシュ通知。**17:30 までに通知が届くこと**を保証ラインとする。

### 4.2 テーマ記事テンプレート（2,000〜3,000字）

- タイトル: 疑問×テーマ型（例「〇〇が動いた理由 ─ △△から考える××」）
- はじめに: 今日起きたことを数字1つで示す
- 1. 数字で見る現状（図①）
- 2. たとえ話で仕組みを理解する
- 3. 関連する日本株（2〜3銘柄の表。データ紹介にとどめる／図②）
- 4. 私の見方・注意点
- 末尾: 有料記事への誘導、Xリンク、免責文

### 4.3 注目銘柄記事テンプレート（2,000〜3,000字）

- タイトル: 銘柄名を先頭（例「【銘柄名(コード)】今日+18%の理由と、データが示す次の論点」）
- はじめに: 今日の値動きを一言で
- 1. 何が起きたか（材料・IR）
- 2. チャートで見る（株価＋出来高／図①）
- 3. 業績・バリュエーション（図②）
- 4. 見ておくべき論点（強気・弱気の両面）
- 末尾: テーマ記事と同じ

### 4.4 文体

- 一人称「私」、です・ます調、落ち着いた解説口調。キャラクター名は名乗らない。
- 読者と同じ投資家目線。難しい概念はたとえ話で補う（既存記事の強み）。
- 推奨表現の代わりに「論点」「データ上は」「私なら〜を確認する」を使う。

### 4.5 X投稿文（記事1本につき2案）

- 案1: 記事の要点を数字1つで示し、noteへのリンクを付ける
- 案2: 問いかけ型
- 140字以内、ハッシュタグ2個まで。

## 5. 図表デザイン

### 5.1 共通ルール

- サイズ: 1280×720px（16:9）、高解像度で書き出す
- 配色: ネイビー `#1E3A5F`（見出し・主系列）、ゴールド `#C9A227`（強調1点のみ）、上昇 `#2E8B57`、下落 `#C0392B`、背景 `#FAF8F3`
- 左上: 結論を一言で書いたタイトル（例「出来高は平常時の9倍」）
- 左下: 出典と日付
- ~~右下: コーギーロゴ（ネイビー版、小さく半透明）~~ → 2026-11-08 ユーザー指示で廃止。代わりに文字を大きく、色をはっきりさせてスマホで拡大せずに読めるようにする
- フォント: Noto Sans JP（クラウド環境に Meiryo UI がないため）
- 画像の隅とファイル名に通し番号（例 `article2_fig1.png`）

### 5.2 図の型

| 型 | 内容 | 主な用途 |
|---|---|---|
| A | 株価（ローソク足または終値線）6か月＋出来高、重要日に注釈 | 注目銘柄 |
| B | 売上・営業利益の棒グラフ、予想は点線 | 注目銘柄 |
| C | 同業比較表（PER・時価総額・騰落率、数値の大小を色の濃さで） | テーマ |
| D | 指標カード（日経・ドル円・SOX 等の大きな数字のタイル） | テーマ冒頭 |
| E | 横棒の順位グラフ（セクター・関連銘柄の騰落率） | テーマ |
| F | 仕組み・たとえ話の図解 | テーマ |

### 5.3 見出し画像（1280×670px）

- 左にコーギー、右にタイトルの要点を大きな文字で
- 背景色: テーマ記事＝ネイビー、注目銘柄記事＝グリーン、有料記事＝ゴールド

### 5.4 コーギー素材の割り当て

- ロゴ: 4枚組の右下（ネイビー版）
- テーマ記事の見出し: 左上（シルクハット版）
- 注目銘柄記事の見出し: 右上（ハンチング帽版）
- 記事の締め: 「Thank you」画像
- 素材は `assets/brand/` に保存する

## 6. 納品ページ

- 非公開アーティファクト、**固定URLを毎日上書き**（サイドバーにピン留め。過去版は履歴に残る）。スマホ向けの縦長1ページ。
- 構成
  1. 冒頭: 3本の一覧（見出し画像の縮小版、タイトル、一行要約、ページ内リンク）
  2. 記事カード（×3）: 見出し画像／タイトル案3つ（各コピー）／本文プレビュー（図は貼る位置に表示）／「本文をコピー」（見出し・太字を保ったリッチテキスト）／図は長押し（PCは右クリック）で保存／X投稿文2案（各コピー）／使った材料と出典（折りたたみ）
  3. 末尾: 選外のネタ候補3〜5件
- 画像はアーティファクトの付属ファイル（`img/*.jpg`、JPEG品質90で1枚100〜200KB）として公開する。
- アーティファクトの閲覧画面はダウンロードリンクを無効にするため、「一括ダウンロード」ボタンは作らない。
- 投稿手順の目標: 1本3〜5分。

## 7. 通知

- 完了時にプッシュ通知（例「🐾 今日のnote 3本ができました：①… ②… ③…」）。

## 8. 失敗時の動き

| 状況 | 動き |
|---|---|
| 東証休場日 | 実行せず終了（通知なし） |
| 引けJSONが古い・取得失敗 | Web検索で補完し、該当図に「Web検索値」と明記 |
| メルマガ未着 | ニュースとデータだけでテーマを選び、ページに注記 |
| 銘柄材料が裏付けできない | その銘柄を使わず次の候補に差し替え。確認できない数字は使わない |
| 3本そろわない | できた本数だけ納品し、通知に本数を明記 |
| 全体失敗 | 「本日は失敗：理由」を通知 |

## 9. 週1回の有料記事

- 分量: 7,000字級、図5〜6枚。既存記事（例: ZenmuTech回）の深掘りスタイルを踏襲。
- 価格: 100〜300円。無料部分で問いと結論の方向性を示し、有料部分に深掘り（業績の逆算、歴史の教訓、論点整理）を置く。
- 見出し画像はゴールド背景。
- **運用開始**: 初回（2026年11月第1週）は対話チャットで手動作成し、型を固める。毎日の日次タスクが1〜2週間安定した後、土曜午前の定期タスクとして自動化する（その週の日次記事から最も深掘りしがいのあるテーマを選ぶ）。

## 10. 動作確認

1. 定期実行を有効にする前に手動で1回実行し、ページの見た目・コピー・画像・note貼り付けをユーザーが確認する。
2. 「本文をコピー → note に貼り付け」で見出し・太字が崩れないことを実機で確認する。
3. 問題なければ平日 16:15 の定期実行を有効にする。

## 11. 実装時の注意（2026-11-04 の有料記事試作で判明）

- 環境のネットワーク設定で Yahoo Finance（`query1.finance.yahoo.com` / `query2.finance.yahoo.com` / `fc.yahoo.com`）が拒否される。図の型A・B（個別銘柄の株価・業績）には許可が必要。
- 長期の米国株データは `raw.githubusercontent.com/datasets/s-and-p-500`（Shiller月次）で取得できる。
- matplotlib は Noto Sans JP の可変フォントを細字（Thin）で描画してしまうため、fontTools で Regular(400)/Bold(700) の静的フォントを作ってから使う。
- `macro_result_closing.json` の日経平均終値（15:35取得）が報道の大引け値と一致しない日がある（11/4: 62,052.73円 vs 62,188.63円）。記事では報道の大引け値を優先し、差異を出典欄に記す。
- 試作の図表スクリプトと納品ページの雛形は、初回有料記事（中間選挙）の納品ページを基準にする。
