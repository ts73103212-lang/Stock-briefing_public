# 出力の構成と書式（既存タスクの書式を踏襲）

平日は「本日の方針」、週末（土・日）は「次週の相場展望」。週末は買い銘柄候補を20選（プライム10・グロース10）に広げて深く分析する。

## 件名
`★重要【新天地メルマガ分析・チーム版】YYYY/MM/DD 本日の方針`（週末は「来週の展望」）

## 構成（この順）
- ⓪ 序文: 今日（週末は次週）の想定シナリオ。デイトレ・スイングの方針を断定形で、認識すべき重要事項を箇条書き
- ① 結論: 今日の"買い"銘柄トップ10選（週末は20選）。表: 銘柄コード｜銘柄名｜セクター｜**終値（前日比）**｜**チャート判定**｜推奨度｜提案理由（2行）
- ② 選定理由: ①の各銘柄について、銘柄ごとに次の順で書く（チャート画像は**推奨度の上位5銘柄、週末は上位10銘柄だけ**。それ以外の銘柄は画像なしで、見出しの判定とチャート分析の文だけ書く）
  1. 見出し: `コード 銘柄名　終値 ¥x,xxx（+x.xx%・MM/DD）　判定: 🟢勝負 / 🟡様子見 / 🔴見送り`
  2. チャート（上位5銘柄・週末は上位10銘柄のみ）: `{{chart:jp_<コード>}}`（この1行だけ書けば、送信時に画像に置き換わる）
  3. 📈 チャート分析（2〜3行）: `signals.json` の数値（週足の向き、日足のEMA5/25の並び、25日線乖離、出来高倍率、20日高値までの距離、RSI）から「今が勝負時期か」を言い切る
  4. なぜ今日か: メルマガのどの記述か、青字/赤字強調の有無、Web検索の裏付け
- ③ 日経平均・TOPIX・プライム or グロースの目線: それぞれ「上目線/下目線」を断定。朝一のポジションはブルかベアか一言で。根拠2〜3行
- ③-2 注目の米国株と日本株への波及（3〜4銘柄。週末は「来週への波及」）: 銘柄ごとに
  1. 見出し: `ティッカー 銘柄名　終値 $xxx.xx（+x.xx%・MM/DD）`
  2. チャート: `{{chart:us_<ティッカー>}}`（左: 米国株の日足、右: 米国株を1日ずらして関連日本株と重ねた60日の動き）
  3. 2〜3行: なぜ注目か（メルマガの言及・周辺セクター、市場目線担当の材料）、過去60日の連動（相関・「米+1%→翌日+x%」・米国株が上げた翌日に日本株が上げた割合）、昨夜の動きから今日（週末は来週）見込まれる日本株への波及。これは実績ではなく見込みとして書く
- ④ 要注意銘柄とセクター: 強調・警戒材料、直近のリスク（決算・規制・金利感応度など）
- ⑤ その他監視銘柄: 10選外で値動きを見るべき銘柄（理由付き、簡潔に）
- ⑥ ユーザー注目銘柄への言及: settings.md の各銘柄について、終値（前日比）とチャート判定を1行、言及・関連材料の要約、なければ「言及なし」（画像は付けない）
- 末尾（チーム版のみ）: 「検証メモ」— メルマガとWeb検索が矛盾した点、確認できなかった点を箇条書き

## 判断の原則
- 最新のメール（特に朝の「NY[日付]」）を最優先。古いメールは補足。矛盾したら最新を採用
- 基本はメルマガを正とし、Web検索でより新しい情報が確認できたときだけ注記する
- 青字強調＝後ろ向き（起きたことの結論）、赤字強調＝前向き（注目・警戒すべきイベント）が多い
- 銘柄は必ず「コード＋銘柄名」。数値は具体的に
- **登場する銘柄には最新の株価（終値と前日比）を必ず書く**。`signals.json` の値を使い、無い銘柄は検証担当の値、それも無ければ「株価取得不可」
- チャートの判定は `signals.json` の `verdict`（勝負/様子見/見送り）をそのまま使う。推奨度とずれてもよいが、ずれる理由を1行で書く（例: 判定は様子見だが、材料が強くデイトレなら勝負）
- チャート画像は開いて見ない。分析は数値から書く

## HTML の書式（Gmail 用）
- 色はすべてインライン style（`style="color:#xxxxxx !important"`）。`<style>` タグは Gmail で消えるので使わない
- 背景は白。色は文字と罫線だけ。装飾は最小限、読みやすさ優先
- 全体: `<div style="font-family:'Meiryo UI',Meiryo,sans-serif;font-size:14px;line-height:1.7;max-width:680px;color:#111111;">`
- セクション見出し: `<div style="border-left:4px solid #1e3a5f;padding-left:10px;font-size:16px;font-weight:bold;margin-top:20px;color:#1e3a5f;">■ 見出し</div>`、続けて `<hr style="border:none;border-top:1px solid #cccccc;margin:6px 0;">`
- 表: `<table border="1" cellpadding="6" cellspacing="0" style="border-collapse:collapse;font-size:13px;width:100%;">`、見出し行は `background-color:#eeeeee;font-weight:bold;`
- プラスの数値は `color:#00aa00`、マイナスは `color:#cc0000`（太字）

## 送信前チェック（PM が確認）
- ⓪と③が断定形か
- ①の銘柄数が10（週末は20）か
- 青字・赤字強調の反映漏れがないか
- Web検索の裏付け・矛盾の注記があるか
- ⑥に settings.md の銘柄がすべてあるか（空欄の銘柄は除く）
- ①の全銘柄に終値（前日比）と判定があり、②の全銘柄に2〜3行のチャート分析があるか。`{{chart:jp_<コード>}}` は上位5銘柄（週末は上位10）だけにあり、それ以外には無いか
- ③-2 に米国株が3〜4銘柄あり、各銘柄に `{{chart:us_<ティッカー>}}` と連動の数値があるか
- 本文の終値・前日比・判定・相関が `signals.json` と一致しているか
