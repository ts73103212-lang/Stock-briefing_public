# 新天地メルマガ分析チーム（試行版）

既存の単独タスク「新天地メルマガ_解読&ドラフト（7:52）」を、サブエージェントのチームで行う試行版。
**個人用の分析**。結果は Gmail の下書き（宛先は本人のみ）にし、第三者に配布しない（有料メルマガの内容に基づくため）。

- 進行役の手順: `orchestrator-prompt.md`（定期タスク 7:27 起動、8:00 までに下書き作成）
- 出力の構成と書式: `output-format.md`
- 役割: `.claude/agents/mm-*.md`

| 役割 | ファイル | モデル | 内容 |
|---|---|---|---|
| メルマガ読解 | `mm-reader` | sonnet | 直近5通の要点、青字・赤字の強調、言及銘柄・セクター、イベント |
| 市場目線 | `mm-market` | sonnet | 前夜の米国市場・先物・為替、日経/TOPIX/プライム・グロースの目線材料 |
| 注目銘柄 | `mm-watchlist` | sonnet | ユーザー注目銘柄（タスクのプロンプトで指定）への言及と直近材料 |
| 銘柄検証 | `mm-stock-checker` | sonnet | 候補銘柄の IR・ニュース・株価の裏取り（候補を半分ずつ2体で並列） |
| アナリスト | `mm-analyst` | opus | 全報告をまとめて下書き HTML を書く |
| PM | `mm-pm` | opus | チェックリストでレビューし、自分で直して確定（時間がないので差戻しはしない） |

個人の設定（注目銘柄・宛先）は公開リポジトリに置かず、定期タスクのプロンプトから `WORK/inputs/settings.md` に書き出して使う。
